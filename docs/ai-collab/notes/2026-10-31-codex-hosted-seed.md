# Turso hosted dan bootstrap owner seed

Pemilik belum memahami setup Turso, sehingga provisioning dilanjutkan lewat Vercel CLI yang sudah terautentikasi. Resource `wedding-invitation-db` berhasil dibuat dan dihubungkan ke Production proyek `acme-d-luh-vi/wedding-invitation`: plan Starter $0/bulan, region Tokyo `hnd1` (Singapore tidak ditawarkan). CLI melaporkan terms diterima melalui browser. Integrasi mengisi TURSO_DATABASE_URL/TURSO_AUTH_TOKEN; migration Drizzle berhasil dan query remote mengonfirmasi tabel invitations tersedia, masih kosong.

Supabase hosted sudah terhubung, tetapi env bertipe Secret ditarik sebagai `[SENSITIVE]`. Jangan menurunkan proteksi kunci. Hasil pull dipindahkan ke `.env.vercel.remote` privat/ignored agar Next.js tidak otomatis memuat placeholder saat build lokal. Build sempat gagal karena `.env.production.local` yang berisi placeholder tersebut; setelah dipindahkan, build lokal lulus. Migrasi remote dapat memakai APP_ENV_FILE=.env.vercel.remote karena hanya membutuhkan Turso; seed lokal tidak bisa memakai placeholder Supabase.

Seed kini menerima SEED_OWNER_EMAIL sebagai alternatif UUID untuk DB kosong. Mencari akun yang sudah ada dengan pagination, atau membuat akun belum terverifikasi tanpa password maupun pengiriman email. Owner demo lama tetap menjadi default; UUID eksplisit tetap diverifikasi dan tidak dapat mengambil alih demo milik akun lain. Tes mencakup pagination, reuse, normalisasi/validasi email, akun baru belum terverifikasi, serta provider error tanpa pembuatan akun.

Typecheck, 21 tes, dan build lokal lulus. Panduan menjelaskan seed sekali dalam build remote dengan konfigurasi sementara --local-config di luar repo. Build rutin tetap hanya npm run build; jangan mengaktifkan seed setiap deploy karena konten demo akan ditimpa.

Pemilik telah memberikan email owner melalui chat; alamatnya tidak dicatat di repo publik. Deployment satu kali dengan buildCommand migrasi → seed → build dan --build-env SEED_OWNER_EMAIL berhasil (dpl_Bwc7dckdi56CwNtcdmshPkhzNJam). Akun owner hosted terverifikasi keberadaannya oleh seed; demo published dan 37 gambar terunggah. Domain utama yang dikembalikan Vercel: https://wedding-invitation-lovat-theta.vercel.app (alias lama acme-d-luh-vi juga tersedia). Functions berada di sin1.

Smoke pertama menemukan cache 404 dari request sebelum seed tetap terbawa lintas deployment. Semua 37 media HEAD sudah 200. `vercel cache dangerously-delete --tag invitation:demo-gaby-afdhal --yes` berhasil menghapus cache tag demo, lalu halaman undangan merespons 200. Ini bukan penghapusan data. Tambahkan langkah invalidasi ini setelah seed eksternal, atau gunakan Publikasikan Ulang dari dashboard.

Smoke hosted lulus: public invitation 200, seluruh 37 media HEAD 200, optimizer Next 200, root 404, login 200, dashboard anonim diarahkan ke login. Browser mobile menguji cover, carousel otomatis, tahan/drag/swipe/release, loop, reduced motion, tanpa overflow/error JS. RSVP melalui form browser tersimpan di Turso dengan jumlah tamu benar; tamu dan respons tes sementara dihapus. Ownership terautentikasi lintas owner sudah diuji lokal sebelumnya, belum diuji ulang pada hosted.

Supabase Site URL dan Redirect URLs perlu cocok dengan domain produksi; pemilik meminta bantuan letaknya dan sudah diberi langkah Vercel Storage → Supabase → Open in Supabase → Authentication → URL Configuration. Belum ada konfirmasi tersimpan. SMTP bawaan Supabase hanya mengirim ke anggota tim proyek; akun owner lain memerlukan SMTP sendiri. Jangan menyatakan login/email production sudah lolos tes sebelum benar-benar diperiksa. Tidak ada email login yang dikirim otomatis oleh agen.
