# Undangan produksi dan RSVP publik

Permintaan pemilik: hapus penyebutan demo dan data tamu/ucapan contoh, jadikan konfirmasi kehadiran dinamis. Branch codex/production-rsvp, keputusan 009 ditulis sebelum mengubah perilaku.

- Undangan lokal dan Turso dipindahkan satu kali ke slug gaby-afdhal; UUID owner/undangan tidak berubah. next.config.ts memberi redirect permanen dari /demo-gaby-afdhal dengan query token tetap. Namespace objek media lama dipertahankan agar semua gambar tetap tersedia.
- Sebelum perubahan, snapshot privat row undangan/tamu/RSVP disimpan di data/backups/production-transition-{local,remote}-*.json (0600, ignored). Penghapusan hanya untuk empat ID seed yang nama dan responsnya masih cocok persis dengan fixture. Tamu atau respons yang berubah tidak dihapus. Kedua lingkungan masing-masing menghapus empat tamu contoh. Rekening placeholder yang cocok persis dihapus dari draft/published, rekening lain dipertahankan.
- Seed sekarang seedInvitation/seedContent/seedSlug memakai fixture gaby-afdhal.json. Hanya inisialisasi jika belum ada; tidak membuat tamu/ucapan/rekening contoh, tidak menimpa konten/status/gambar existing, tidak mengambil alih owner.
- RSVP umum menerima nama (maks 100), status, jumlah (1–20), ucapan (maks 500); honeypot tersembunyi. Server membuat token random 128-bit, menyimpan ke cookie rsvp-<slug> HttpOnly/SameSite=Lax/Secure pada HTTPS, path spesifik undangan. Query cookie ikut menentukan respons pribadi saat reload. Cookie hilang/perangkat baru membuat respons baru; nama tidak dipakai sebagai identitas/deduplikasi. Identitas pengisi publik tidak diverifikasi.
- Transaksi memastikan undangan published, batas jumlah, satu respons per guest, isolasi antar-undangan, dan mempertahankan status moderasi. Link personal tetap memakai kuota owner. revalidatePath memperbarui ucapan segera setelah submit. Preview owner tetap menonaktifkan form.
- Audit saat smoke menemukan getGuestByToken sebelumnya memilih shareToken dalam object yang diserialisasi ke client. Query publik kini hanya memilih enam field template; token cookie tidak ikut HTML/RSC/client props. Smoke regresi gagal sebelum perbaikan proyeksi dan lulus setelah deploy final (dpl_3nznZ9yrVskKFmE7UQzVDUnDz2BF).

Validasi lokal: typecheck, 24 tes, build lulus. Unit test mencakup pembuatan/pembaruan visitor, tidak merge nama sama, isolasi token lintas undangan, quota/published, moderasi dan seed tanpa data contoh/overwrite. Smoke hosted awal: route produksi 200, redirect lama 308/query tetap, gambar existing 200; form publik bisa kirim, ucapan langsung tampil, cookie aman, reload mengenali tamu, pembaruan tidak menggandakan respons dan moderasi tetap. Data smoke sementara selalu dihapus lewat finally. Smoke final hosted lulus termasuk validasi nama kosong oleh server, token tidak berada di HTML/client props, cookie aman, kirim/reload/update respons, dan moderasi. Tamu/ucapan tes dibersihkan. Smoke link personal juga lulus: nama tetap read-only, RSVP tersimpan, carousel/cover tetap sesuai prototype.

Pending yang tidak termasuk perubahan ini: callback/login Supabase belum dikonfirmasi pemilik. Proteksi volumetrik tetap memerlukan WAF; honeypot bukan rate limiter. Tidak ada perubahan schema/migration database.
