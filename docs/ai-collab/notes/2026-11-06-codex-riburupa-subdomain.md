# Persiapan domain RibuRupa

Pemilik meminta repo disiapkan untuk subdomain riburupa.com dan memilih invitation.riburupa.com. Situs induk dibaca melalui web; judulnya “RibuRupa — Web dan Multimedia untuk Bisnis”. DNS publik menunjukkan Cloudflare, dengan NS devin.ns.cloudflare.com dan zoe.ns.cloudflare.com. Tidak ada CNAME/A untuk subdomain saat pemeriksaan.

Branch codex/riburupa-subdomain memperketat SITE_URL menjadi origin HTTP(S) tanpa kredensial/path/query/fragment dan menormalisasi trailing slash. HTTPS tetap wajib di Vercel. Link tamu, login, metadata dan callback sudah memakai env bersama; tidak menambah basePath atau hardcode hostname pada komponen. Panduan docs/deploy-riburupa.md berisi nilai DNS, urutan aktivasi, callback, dampak cookie/PKCE, SMTP dan rollback. Contoh env, README dan howto ditautkan; petunjuk lama tentang kebutuhan secret key pada howto diperbarui sesuai fitur upload musik.

Vercel CLI 65.12.1: SITE_URL Production ditambahkan eksplisit sebagai Config dengan nilai domain lama https://wedding-invitation-lovat-theta.vercel.app agar fallback VERCEL_PROJECT_PRODUCTION_URL tidak mengganti origin sebelum waktunya. Domain invitation.riburupa.com ditambahkan ke proyek wedding-invitation (scope acme-d-luh-vi); ownership verified, project attached. `vercel domains verify` memberi invalid_configuration karena record DNS belum ada, tanpa konflik. Rekomendasi spesifik proyek: CNAME invitation → 63d20240d6610afa.vercel-dns-017.com, disableProxy true. Ini hanya persiapan; DNS Cloudflare dan konfigurasi Supabase belum diubah.

Vercel menyediakan Domain Connect untuk pemilik meninjau/menerapkan DNS lewat Cloudflare; dapat dibuka dari Settings → Domains. Setelah DNS/TLS siap, tambahkan callback https://invitation.riburupa.com/auth/callback dan Site URL baru di Supabase; simpan callback lama selama transisi. Baru setelah itu ubah SITE_URL Production dan redeploy. Login harus dimulai dari domain yang sama dengan callback karena verifier PKCE tersimpan di cookie. Jika menerapkan redirect alias lama, pertahankan path/query dan uji link personal. Cookie RSVP/login tidak bermigrasi otomatis.

Validasi: typecheck, 28 tes, build konfigurasi lokal dan build dengan SITE_URL=https://invitation.riburupa.com lulus. Smoke lokal hasil build custom-origin: undangan 200, Open Graph image memakai subdomain baru, callback invalid tetap menuju origin tepercaya walau Host request dipalsukan, root/home tetap 404. Tidak mengirim email atau mengubah data undangan. Aktivasi DNS/HTTPS dan login melalui domain baru belum diuji. Custom SMTP masih belum disiapkan/diketahui menurut jawaban pemilik sebelumnya.
